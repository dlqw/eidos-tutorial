# Principled `do` elaboration

- Sync ID: `eidos-functional-obligation-do-0.9`
- Classification: feature
- Latest immutable Eidos core release: `0.8.0-alpha.1`
- Target Eidos core version: `0.9.0-alpha.1`

## Added

- Documented the `do` expression grammar for effectful pattern binds, pure local bindings, and final expressions.
- Documented the shared type-constructor and Monad evidence contract, plus `Alternative.empty` failure semantics for refutable bind patterns.
- Added `examples/72_principled_do.eidos` with independent Option binds, dependent fallback to sequential Monad lowering, and refutable pattern success/failure paths.

## Changed

- Explained that the compiler may combine independent adjacent binds through left-to-right Applicative operations only after dependency, effect, ownership, evidence, and pattern proofs succeed.
- Clarified that no `map2`, optimizer hint, builder, capacity value, or compiler-preferred container is required for this optimization.

## Migration

- Existing `do` syntax is unchanged. Refutable binds now require coherent `Alternative` evidence so mismatch has a defined empty result instead of a partial-match behavior.
