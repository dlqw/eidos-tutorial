# Curried binder lists

- Sync ID: `eidos-2026-07-28-curried-binder-list`
- Classification: feature
- Latest immutable Eidos language release: `0.4.0-alpha.1`
- Target Eidos language version: `0.9.0-alpha.1`

## Added

- Added `p1, p2 => body` as the canonical spelling of the right-associated curried branch `p1 => p2 => body` in function bodies and braced lambdas.
- Defined `(p1, p2) => body` as one tuple parameter and `(a1, a2), (b1, b2) => body` as two curried tuple parameters.
- Defined binder-list guards to run after all listed binders have matched while retaining arrow chains for staged guards.

## Migration

- Remove the outer tuple parentheses when an old `(p1, p2) => body` branch meant two curried parameters.
- Keep the parentheses when the function truly accepts one tuple.
