# Eidos 0.8.0-alpha.1

- Added implicit function bodies for functions whose first runtime parameter is `Unit`.
- Added fixed binary `then` / `else` selection for canonical `Bool`, `Option`, `Result`, and right-biased `Either` values, including grouped subjects and arm-local payload placeholders.
- Documented the exact single-arm `Unit` fallback, evaluation order, payload visibility, formatter layout, migration boundaries, and continued support for `if`, `if let`, `while let`, and full `match`.
- Added the verified `71_implicit_unit_selection.eidos` example and moved tutorial manifests and Eidosc compatibility metadata to the Eidos 0.8 release line.
